# Hi-Cycles Public Website

The public website for the Hi-Cycles research group at the University of Hawai'i at Mānoa, built with [Astro](https://astro.build/) and the [Starlight](https://starlight.astro.build/) documentation theme.

## Getting started

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

The site will be available at <http://localhost:4321>.

### Build for production

```bash
npm run build
```

The production output is written to `dist/`.

### Preview the production build

```bash
npm run preview
```

## Content

Site content lives in `src/content/docs/`. Add or edit `.md` / `.mdx` files there to update the site.

Configuration (title, sidebar, social links, etc.) is managed in `astro.config.mjs`.
